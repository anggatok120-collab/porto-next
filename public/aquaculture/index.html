📐 Arsitektur Hardware & Alur Jaringan Telemetri

End-to-End Pipeline
1️⃣ Sensor Akuakultur
Sensor pH probe industri, optical DO, waterproof DS18B20, dan nephelometric turbidity yang ditempatkan pada titik sirkulasi kolam.
Analog / OneWire 3.3V
2️⃣ Edge Microcontroller
ESP32 dual-core (FreeRTOS) bertugas sampling sensor dengan moving average filter, kalibrasi analog 16-bit, dan kontrol relay aktuator.
ESP32 · FreeRTOS · ADS1115
3️⃣ Transmisi Jaringan
Gateway MikroTik di area tambak memancarkan WiFi 2.4GHz ke node, mengirimkan payload MQTT melalui protokol TCP/TLS dengan QoS 1.
MikroTik Router · MQTT · TLS
4️⃣ Cloud & Alert Dispatch
Dashboard real-time memvisualisasikan data telemetri, sedangkan Bot Telegram otomatis mengirim alert jika parameter air melampaui batas aman.
Next.js Edge · Telegram NOC Bot
